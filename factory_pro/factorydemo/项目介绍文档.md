# 智慧工厂安全监测平台 · 前端介绍文档

## 一、项目概述

本项目是一个面向智慧工厂的**安全监测与设备管理平台**前端，采用深蓝科技风视觉设计，集成了 3D 数字孪生、环境监测、设备管理、告警中心、能耗统计等模块，实现对工厂生产环境与设备运行状态的实时可视化监控。

平台覆盖三类核心对象的统一管理：
- **生产设备**：组装线、流水线、工作台、压合工装、测试工装、包装设备等
- **环境传感器**：温湿度传感器（TH-XX）、气体传感器（GAS-XX）
- **智能终端**：AGV 搬运车、光电计数器、红外照明设备

## 四、功能模块

### 1. 综合监控大屏（Dashboard）
平台首页，集中展示核心运行指标：
- **KPI 卡片**：在线设备数、平均温度、平均湿度、活跃告警数
- **设备状态分布饼图**：在线 / 离线 / 预警 / 告警 / 充电中 / 维护中
- **温湿度节点列表**：各厂区 TH-XX 传感器实时数值
- **气体浓度监测**：GAS-XX 传感器浓度与阈值对比
- **最近告警**：最新 6 条告警记录

### 2. 3D 数字孪生（DigitalTwin）
基于 Three.js 构建的工厂三维可视化场景：
- **三厂切换**：A 厂（台式机总装）、B 厂（笔记本生产）、C 厂（服务器生产）
- **生产设备建模**：按工段（总装→测试→包装）布局，每种设备有专属 3D 模型
- **环境传感器**：温湿度传感器（壁挂数显盒）、气体传感器（探测器+感应罩）沿厂房内墙布置
- **实时标签**：设备悬浮显示温度/振动/功率，传感器显示温湿度或气体浓度
- **交互**：点击设备/传感器弹出详情面板，支持视角切换、自动巡航、热点动画

### 3. 设备管理（Device）
统一管理全厂设备（含传感器）：
- **统计栏**：总设备、在线、离线、告警数量
- **筛选与搜索**：按设备类型筛选、按名称/ID 搜索
- **设备卡片**：展示类型、位置、状态；生产设备显示信号强度，温湿度传感器显示温湿度值，气体传感器显示浓度与阈值
- **排序规则**：温湿度传感器 → 气体传感器 → 生产设备，同组按 ID 升序

### 4. 温湿度监控（Temperature）
- 12 个温湿度节点（TH-01 ~ TH-12）的实时数值与状态
- 温度/湿度趋势折线图
- 超阈值预警高亮

### 5. 废气监测（GasMonitor）
- 6 个气体传感器（GAS-01 ~ GAS-06），覆盖 CO、烟雾、VOC、CO₂
- 浓度实时值与告警阈值对比
- 超标节点告警提示

### 6. 红外照明控制（Lighting）
- 照明开关与亮度调节
- 红外感应状态展示

### 7. AGV 避障系统（AGV）
- AGV 运行状态、电量、障碍物检测

### 8. 货物感应计数（Counter）
- 光电计数器实时计数
- 各产线货物统计

### 9. 告警中心（Alarm）
- 全平台告警集中展示（温度、气体、设备、AGV）
- 按严重程度分级（严重/警告/信息）
- 告警确认与处理

### 10. 能耗统计（Energy）
- 各设备/车间能耗数据
- 能耗排名与趋势分析

### 11. 环境安全评估（Safety）
- 隐患排查记录表
- 安全改善建议
- 安全评分雷达图

### 12. 数据报表（Report）
- 各类监测数据的统计报表

## 五、数据架构与统一数据源

### 统一数据源：`allDevices`

`src/stores/device.js` 中的 `allDevices` 计算属性是全平台设备数据的**唯一数据源**，将三类设备归一化到统一结构：

| 来源 | 编号规则 | type | 状态来源 |
|---|---|---|---|
| 生产设备 | ASSY_*, WORKSTATION_* 等 | 原值 | 设备自身 status |
| 温湿度传感器 | TH-01 ~ TH-12 | `tempHumid` | online / warning / danger |
| 气体传感器 | GAS-01 ~ GAS-06 | `gas` | 按 value vs threshold 自动判定 |

每条记录统一字段：`id`、`name`、`type`、`location`、`status`、`statusLabel`，传感器额外携带 `temp/humid` 或 `value/unit/threshold/gasType`。

### 数据流向

```
deviceStore.simulateData()  [每 5 秒，AdminLayout 触发]
    ↓
tempHumidNodes / gasNodes / devices
    ↓
allDevices（计算属性，自动归一化 + 排序）
    ↓
┌─────────────────┬──────────────────┬──────────────────┐
│  综合监控大屏    │   设备管理页      │  3D 数字孪生      │
│ (onlineCount    │  (卡片列表)       │ (传感器模型+标签) │
│  /totalCount)   │                  │                  │
└─────────────────┴──────────────────┴──────────────────┘
    ↓
温湿度监控页 / 气体监测页（直接读取 tempHumidNodes / gasNodes）
```

**编号统一性**：TH-XX / GAS-XX 在设备管理、3D 大屏、温湿度/气体监测页中完全一致，数据同源。

### 实时数据模拟

`simulateData()` 每 5 秒执行一次，模拟温湿度、气体浓度、货物计数等数据波动，为前端提供实时数据驱动。当前无后端接口时，前端使用 store 内置数据；若后端可用，通过 `request.js` 对接 `/api` 接口。

## 六、权限与路由

### 路由守卫（`router/index.js`）
- **登录态校验**：未登录用户访问需认证页面 → 跳转 `/login`
- **管理员权限**：标记 `adminOnly` 的页面（3D 场景、设备管理、数据报表）仅管理员可访问

### 用户角色（`stores/user.js`）

| 角色 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 管理员 | admin | admin123 | 全部页面 |
| 普通用户 | user | user123 | 除管理页外的全部页面 |
| 注册用户 | 自定义 | 自定义 | 普通用户权限（管理员注册码 `2026`） |

注册信息持久化到 `localStorage`。

## 九、后端对接说明

当前前端内置完整的 mock 数据，可独立运行。后端接口约定：

- **基础地址**：`http://localhost:8088/api`
- **认证方式**：`Authorization` 请求头携带 token
- **接口风格**：RESTful，响应格式 `{ success, data, message }`
- **关键接口**：
  - `GET /digital-twin/devices` — 设备列表
  - `GET /digital-twin/status` — 设备实时状态

业务层对接口失败做了静默兜底，自动回退到 store 内置模拟数据，保证前后端解耦开发。
